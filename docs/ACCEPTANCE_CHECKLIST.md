The literal XSOTA-1 gate remains separate. It requires every declared public stratum to beat the matched AnaFlow row on all preregistered endpoints. TT-only capability rows, parser-only smoke tests, and source suites without a common PVT metric cannot satisfy that gate. The finite matrix therefore does not support a universal all-circuit, all-PDK, all-simulator SOTA statement.
