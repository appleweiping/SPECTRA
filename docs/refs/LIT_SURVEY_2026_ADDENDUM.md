# 2026 analog-sizing literature addendum

**Audit date:** 2026-11-20  
**Project:** SPECTRA  
**Evidence rule:** every row below has a primary arXiv/PMLR page or an official code repository. Claims copied from an abstract or README are marked as abstract/README evidence. They are not treated as independently reproduced results.

This addendum updates the broader survey in [`LIT_SURVEY.md`](LIT_SURVEY.md). It keeps heterogeneous generation, sizing, PVT optimization, surrogate modeling, and long-horizon agent evaluation in separate strata. A method is not promoted into the common SIZ7g ranking merely because it uses an LLM or a simulator.

## Protocol consequences

1. The common SIZ7g table remains fixed at 300 simulator evaluations, 12 LLM calls and seeds 0/1/2. New papers with 16k, 40-run, surrogate or two-hour budgets receive separate receipts.
2. Every new external row must declare topology, PDK/model, simulator version, seed policy, metric parser, corner list, budget, failure taxonomy and whether the verifier is independent of the agent.
3. PVT claims require all declared corners to be evaluated. A TT-only or source-capability result stays outside PVT ranking.
4. Component claims require a matched removal or replacement. Topology understanding, knowledge retrieval, role specialization, diagnosis, intent representation, adaptive worst-corner refinement and surrogate calibration are separate axes.
5. The current SPECTRA evidence supports measured-scope comparisons. These sources strengthen the benchmark and protocol design, but they do not prove a universal all-circuit, all-PDK, all-simulator SOTA claim.
