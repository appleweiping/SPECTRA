\section{Theoretical Properties of Design-Intent Parameterization}
\label{app:theory}

\subsection{Monotone Inversion of Pre-Characterized BSIM4 Lookup Tables}
For each SKY130 $1.8\,\mathrm{V}$ MOSFET flavor ($\text{dev} \in \{\text{nFET}, \text{pFET}\}$), process corner $c \in \{\text{TT, FF, SS, SF, FS}\}$, and temperature $T \in \{-40, 27, 125\,^\circ\mathrm{C}\}$, \textsc{SPECTRA} pre-computes DC and small-signal operating-point arrays at reference finger width $W_{\text{ref}} = 5\,\mu\mathrm{m}$ over an $11 \times 10 \times 5 \times 181$ grid of channel length $L \in [0.15, 20]\,\mu\mathrm{m}$ (logarithmically spaced), drain-to-source voltage $V_{DS} \in [0.05, 1.80]\,\mathrm{V}$, bulk-to-source reverse bias $V_{SB} \in [0.0, 1.2]\,\mathrm{V}$, and gate-to-source voltage $V_{GS} \in [0.0, 1.80]\,\mathrm{V}$ ($10\,\mathrm{mV}$ step).

\textbf{Proposition 1 (Well-Posed Geometry Mapping).} \emph{Fix device flavor, corner, and temperature, and consider an interpolated slice $(L, V_{DS}, V_{SB})$ obtained by trilinear interpolation over $(\log L, V_{DS}, V_{SB})$. Let $\eta_{\max} = \max_{V_{GS}} (g_m / I_D)(V_{GS})$ denote peak transconductance efficiency near weak inversion, and restrict queries to the moderate-to-strong inversion branch $\mathcal{I} = [V_{GS}(\eta_{\max}), 1.8\,\mathrm{V}]$ where $(g_m / I_D)(V_{GS})$ is strictly decreasing and normalized current density $J_D(V_{GS}) = I_D(V_{GS}) / W_{\text{ref}}$ is strictly increasing. Then for every clamped target $\tilde{\eta} = \operatorname{clip}(\eta, \eta_{\min}, \eta_{\max})$ and branch current $I_D > 0$, there exists a unique bias $V_{GS}^* \in \mathcal{I}$ and unique positive width $W^* = W_{\text{ref}} \cdot I_D / J_D(V_{GS}^*)$ satisfying first-order width scaling.}

\emph{Proof Sketch.} Above deep subthreshold leakage in BSIM4, channel current $I_D(V_{GS})$ is strictly increasing and log-concave in $V_{GS}$, so its logarithmic derivative $\eta(V_{GS}) = \frac{\partial \ln I_D}{\partial V_{GS}} = \frac{g_m}{I_D}$ decreases strictly from the subthreshold slope limit $1/(n U_T) \approx 22\text{--}26\,\mathrm{S/A}$ (nFET) or $16\text{--}19\,\mathrm{S/A}$ (pFET) toward strong-inversion velocity saturation ($\approx 3\text{--}5\,\mathrm{S/A}$). Piece-wise linear inversion on the 181-point $V_{GS}$ grid therefore defines a continuous bijection $\tilde{\eta} \mapsto V_{GS}^* \in \mathcal{I}$, yielding $(W^*, V_{GS}^*, V_{dsat}^*, g_m^*, g_{ds}^*)$. Decomposing $W^*$ into $m = \max(1, \lceil W^* / W_{\text{ref}} \rceil)$ fingers of width $W^* / m \le 5\,\mu\mathrm{m}$ suppresses narrow/wide-width geometry drift between the LUT reference device and the compiled SKY130 subcircuit. \hfill $\square$

\subsection{Manifold Invariance and Capped Minimax Boundedness}
\textbf{Proposition 2 (Exact Structural Invariance).} \emph{Let $\mathcal{M} \subset \mathbb{R}_{>0}^{D_{\text{raw}}}$ denote the manifold of symmetry-preserving device sizings defined by $k$ algebraic design invariants $g_j(w) = 0$ (differential pair matching $W_1 = W_2, L_1 = L_2$; mirror ratios $W_4 / W_3 = \alpha$; RHP-zero tracking $R_z g_{m7}(w) = k_z$). If a design-intent program parameterizes $w = \Phi(u)$ ($u \in [0,1]^d$, $d < D_{\text{raw}}$) by sharing intent coordinates across matched pairs and computing tracking passives from LUT-queried $g_m^*$, then $\Phi([0,1]^d) \subseteq \mathcal{M}$, whereas isotropic random or TPE sampling in $[0,1]^{D_{\text{raw}}}$ assigns $\mathcal{M}$ zero Lebesgue measure whenever $k \ge 1$.}

Furthermore, because each per-metric shortfall is capped via $\tilde{v}_s = \min(2, v_s(m_{s,c})) \in [0, 2]$, the worst-corner objective $\mathcal{V}_{\mathcal{C}}(p) = \max_{c \in \mathcal{C}} \sum_{s \in \mathcal{S}} \tilde{v}_s(m_{s,c}(N(p)))$ satisfies $0 \le \mathcal{V}_{\mathcal{C}}(p) \le 2|\mathcal{S}|$ for all $p$, with $\mathcal{V}_{\mathcal{C}}(p) = 0$ if and only if every specification $s \in \mathcal{S}$ holds at every condition $c \in \mathcal{C}$. This boundedness prevents singular transient or AC extraction failures on infeasible candidates from destabilizing CMA-ES rank-mu covariance updates.

\section{Closed-Loop Algorithm and Rule Base}
\label{app:algo}

\textbf{Closed-Loop Synthesis Procedure.} Given specification $\mathcal{T}$, budgets $(B_{\text{LLM}}, B_{\text{sim}})$, and BSIM4 LUTs:
(1) \emph{Plan}: Query LLM with $x_{\text{NL}}$, $\mathcal{P}_{\text{io}}$, SKY130 PDK sheet, and family topology cards ($1$ call) to synthesize initial Python module $(\texttt{PARAMS}, \texttt{design})$.
(2) \emph{Execute \& Static Check}: Run \texttt{design}$(p^{(0)}, \text{lut}, \text{spec})$ in an isolated subprocess to emit $(N, \hat{m})$; run canonical parser and ERC ($0$ sims). If ERC fails, pass verbatim errors to the repair loop.
(3) \emph{Evaluate \& Diagnose}: Simulate $N$ on $c_{\text{TT}}$ ($1$ sim). If nominal constraints pass and $\mathcal{C}_{\text{eval}} = \{c_{\text{TT}}\}$, terminate. If nominal constraints pass on a robust task, invoke \emph{Adaptive PVT Closure} (Step 5). Otherwise, compute four-channel diagnosis $\mathcal{D}$ (including $+10\%$ finite-difference sensitivities on up to $8$ parameters when $\mathcal{V} < 4$ and a $1$-sim directional local probe on nominal tasks) and retrieve targeted knowledge cards.
(4) \emph{Hierarchical Policy}: Query LLM ($1$ call) with $(N, \mathcal{D}, \text{cards}, \text{history})$ to choose \textsc{Edit} (update Python module), \textsc{Refine} (run trust-region CMA-ES over top $d_{\text{act}} \le 4$ attributed intent variables within radius $r_t = \min(0.25, 0.08 + 0.02 t)$, $0$ calls), or \textsc{Declare-Infeasible}.
(5) \emph{Adaptive PVT Closure}: Sweep $\mathcal{C}_{\text{PVT}}$ ($45$ sims). If $\mathcal{V}_{\mathcal{C}_{\text{PVT}}} = 0$, return $N$. Otherwise initialize $\mathcal{C}_1 = \{c_{\text{TT}}\} \cup \operatorname{Top-2}(\mathcal{C}_{\text{PVT}})$ and run up to $3$ rounds of trust-region CMA-ES on $\mathcal{C}_r$ followed by $45$-corner re-verification, appending up to two newly worst corners per round ($|\mathcal{C}_r| \le 6$). Return persistent corner failures to Step 4 until budgets expire.

\textbf{Causal Diagnosis Rules and Sandboxed DSL.} The sandboxed Python DSL exposes only \texttt{Netlist} (\texttt{.dev}, \texttt{.M}, \texttt{.Q}, \texttt{.R}, \texttt{.C}), \texttt{lut} (\texttt{.size}, \texttt{.op}, \texttt{.table}, \texttt{.at}), \texttt{par}, \texttt{db}, \texttt{PI}, \texttt{UT}, and \texttt{math}, blocking file I/O, imports, and reflection. The 17 deterministic diagnosis rules combine 4 universal MOSFET operating-region rules (triode $V_{DS} < V_{dsat}$, saturation-edge margin $V_{DS} - V_{dsat} < 50\,\mathrm{mV}$, cutoff $I_D < 1\,\mathrm{nA}$, unintended subthreshold $V_{GS} < V_{th} - 50\,\mathrm{mV}$) with 13 circuit-family rules: rail-pinned DC output ($V_{\text{out,DC}} \notin [0.25, 1.55]\,\mathrm{V}$), phase-margin non-dominant pole crowding, low DC gain $g_m r_o$ bottleneck, bandwidth $g_m / C_L$ shortfall, output-stack swing clipping, tail/output slew limiting, tail-impedance CMRR degradation, LDO load-step ringing and loop-gain regulation, bandgap startup zero-current lockup and PTAT/CTAT slope imbalance, continuous-time comparator polarity inversion, and clocked latch incomplete regeneration.

\textbf{Cross-Vendor Backbone Consistency and Public Multi-PDK Coverage.} On an earlier 33-task cross-tier sweep using Claude Opus 5.5 (\textsc{E1}), \textsc{SPECTRA} reached $88.9\%$ overall success ($100\%$ T1, $100\%$ T2, $96.7\%$ T3, $95.2\%$ Designer) versus $85.9\%$ for AnalogCoder-style ($73.3\%$ T3), $80.8\%$ for SPECTRA-min ($83.3\%$ T3), and $59.1\%$ for Gen+TPE ($48.3\%$ T3; primary Holm $p=0.0035$), confirming that near-frontier T3 and PVT tiers drive discrimination across LLM families while T1/T2 saturate. Across public cross-PDK capability checks (3 seeds, 300 simulations), \textsc{SPECTRA} and AnaFlow both achieve $100\%$ TT pass on \texttt{ASAP7} $7\,\mathrm{nm}$ FinFET LDOs, SKY130 LP op-amps, and discrete BJT common-emitter stages (under both \texttt{ngspice-44.2} and \texttt{Xyce-7.10}), while \textsc{SPECTRA} reduces TT violation on \texttt{PTM45} ($0.2298$ vs.\ $0.2816$). On \texttt{SGAnalog}'s \texttt{Xyce} AC compatibility probe, all 17 source decks hit an upstream \texttt{ngspice}-specific mismatch expression unsupported by \texttt{Xyce}, documenting an explicit simulator-syntax boundary separate from sizing performance.
