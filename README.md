# SPECTRA — Spec-to-Robust Analog Circuit Synthesis with LLM Agents

End-to-end agentic analog circuit generation: natural-language specification → topology → device sizing →
PVT-robust SPICE verification on the open SkyWater SKY130 PDK (ngspice-42).

Research is conducted following the ARIS workflow (Auto-claude-code-research-in-sleep):
`RESEARCH_BRIEF.md` → `idea-stage/` → `refine-logs/` → experiments → `review-stage/` → `paper/`.

## Layout
- `spectra/sim` — ngspice runner, testbenches, measurements, PVT/Monte-Carlo
- `spectra/bench` — benchmark tasks (spec-driven + functional)
- `spectra/agent` — the SPECTRA agent
- `spectra/baselines` — baseline agents and optimizers
- `pdk/sky130` — minimal SKY130 1.8 V FET models (Apache-2.0, from google/skywater-pdk-libs-sky130_fd_pr)
- `data/lut` — gm/Id lookup tables generated by `scripts/gen_lut.py`
- `tools/aris_review.py` — ARIS reviewer bridge (fresh `claude -p` sessions)

## Requirements
Python ≥ 3.10, numpy, scipy; ngspice ≥ 42; `claude` CLI for LLM calls.
